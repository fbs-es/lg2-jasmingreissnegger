# API Reference

See the class index below for full API documentation of every public class in this project.

## Classes

- [Customer](Fbs.Lg2.Customer.html) — a buyer who can submit reviews for products
- [Manufacturer](Fbs.Lg2.Manufacturer.html) — a manufacturer that produces one or more products
- [Product](Fbs.Lg2.Product.html) — a product sold through the e-commerce portal
- [Review](Fbs.Lg2.Review.html) — a review submitted by a customer for a product
- [Reply](Fbs.Lg2.Reply.html) — a vendor's reply to a single review
